# 💬 Chat App 1.0

A simple real-time chat application built using **Node.js**, **Express**, and **Socket.io**. This project demonstrates the fundamentals of WebSockets and live communication between users in a web environment.
https://chat-app-1-0-6say.onrender.com/login
---

## ⚙️ Features

- 🧑‍🤝‍🧑 Real-time communication between multiple users
- 💬 Join chat rooms with usernames
- 📡 Powered by **Socket.io** for instant message delivery
- 🚀 Fast and lightweight Node.js backend
- 🌐 Basic front-end UI for chat interface

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js, Socket.io  
- **Frontend:** HTML, CSS, JavaScript  
- **Runtime:** WebSockets for real-time data transfer
